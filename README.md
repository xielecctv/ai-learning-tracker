# AI 学习计划追踪器

一个用 HTML、CSS、JavaScript 制作的中文网页 App，用来记录和管理 AI 编程学习任务。

这个项目适合作为 Vibe coding 的第一个练习项目：没有 React、没有后端、没有数据库，也没有接入 AI API。数据保存在浏览器的 localStorage 中，刷新页面后不会丢失。

## v0.2 功能

- 添加学习任务
- 编辑学习任务
- 删除学习任务
- 设置任务分类
- 设置任务状态
- 设置截止日期
- 首页显示今日到期任务
- 首页显示逾期未完成任务
- 按状态筛选任务
- 按分类筛选任务
- 搜索任务名称和备注
- 按截止日期排序
- 重置搜索和筛选条件
- 学习进度仪表盘
- 导出任务数据为 JSON 文件
- 从 JSON 文件导入任务数据
- 使用 localStorage 保存数据

## 文件说明

```text
ai-learning-tracker/
├── index.html
├── style.css
├── app.js
└── README.md
```

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构，包含表单、筛选器、任务列表和提醒区域 |
| `style.css` | 页面样式，让 App 更清晰易用 |

## 如何使用

直接用浏览器打开 `index.html` 即可使用。

如果发布到 GitHub Pages，只需要把这几个文件放到仓库根目录，然后在 GitHub 仓库设置中开启 Pages。

## 测试建议

1. 添加一个任务，确认任务出现在列表中。
2. 刷新页面，确认任务仍然存在。
3. 编辑任务，确认修改后的内容被保存。
4. 删除任务，确认任务从列表中消失。
5. 添加一个截止日期为今天的未完成任务，确认它出现在“今日到期任务”中。
6. 添加一个截止日期早于今天的未完成任务，确认它出现在“逾期未完成任务”中。
7. 把逾期任务状态改为“已完成”，确认它不再显示为逾期。
8. 使用状态筛选和分类筛选，确认列表只显示符合条件的任务。
9. 输入任务标题或备注关键词，确认搜索结果正确。
10. 切换截止日期排序，确认任务顺序正确。
11. 点击“重置筛选”，确认搜索词、状态筛选、分类筛选和排序恢复默认。
12. 点击“导出数据”，确认可以下载 `ai-learning-tracker-backup.json`。
13. 选择正确的 JSON 文件导入，确认任务被恢复并写入 localStorage。
14. 选择错误格式的 JSON 文件导入，确认页面不会崩溃，并显示错误提示。
